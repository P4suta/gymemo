# Japanese artwork

[Editable Figma artwork](https://www.figma.com/design/Hid7RVq16U5SizfgMTQRZB/?node-id=214-3) contains the Header and Search Results compositions.
The Portable Network Graphics (PNG) exports use opaque `sRGB`.
The Header measures 3840 by 1646 pixels.
Search Results measures 3840 by 2560 pixels.

The compositions follow [Apple's asset guidance](https://developer.apple.com/app-store/asset-best-practices/) and its [creative asset specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications).
The [official template](https://devimages-cdn.apple.com/design/resources/download/app-store/creative_assets-templates.sketch) places the Header art safe area at x=1097, y=493, width=1646, height=661.
The Search Results art safe area is at x=836, y=765, width=2168, height=1030.
The product name and purpose stay inside those areas, together with the primary set logging content in Search Results.
The app depiction preserves native system colors, while the surrounding artwork uses black and white.
